## ✨ Sobre o Projeto

<table>
<tr>
<td width="50%" valign="top">

### 🎯 Objetivo

Desenvolver um único sistema em **Java Swing**, utilizando **Programação Orientada a Objetos**, **JDBC**, **Banco de Dados** e **CRUD completo**, disponibilizando duas versões da interface gráfica.

</td>

<td width="50%" valign="top">

### 🖥️ Interfaces

- SDI (Single Document Interface)
- MDI (Multiple Document Interface)
- Integração com Banco de Dados
- Navegação por Menus
- JTable para consultas

</td>
</tr>
